# Лабораторна робота №3. Знайомство з нейронними мережами

## Мета роботи

Ознайомитися з основними принципами побудови та навчання нейронних мереж для різних типів даних: табличних даних, зображень і текстів. Дослідити процес навчання моделей, проаналізувати learning curves та порівняти нейромережеві підходи з класичними алгоритмами машинного навчання.

## Використані технології

- Python
- PyTorch
- Torchvision
- Scikit-learn
- NumPy
- Pandas
- Matplotlib
- GloVe (pretrained word embeddings)
- Google Colab

## Структура роботи

### 1. Повнозв'язані нейронні мережі (MLP)

Для виконання завдання використано датасет `Cybersecurity Intrusion Detection Dataset` з лабораторної роботи №1.

Побудовано повнозв'язану нейронну мережу (MLP) для бінарної класифікації мережевих сесій на нормальні та потенційно атаковані.

У процесі роботи:
- виконано попередню обробку табличних даних;
- проведено кодування категоріальних ознак;
- побудовано та навчено MLP за допомогою PyTorch;
- оцінено якість моделі на тестовій вибірці;
- побудовано learning curves;
- порівняно результати з класичними алгоритмами машинного навчання з лабораторної роботи №1.

**Результати:**

| Модель | Test Accuracy |
|---|---:|
| Random Forest | 88,31% |
| MLP (PyTorch) | 88,21% |
| SVM | 88,10% |
| AdaBoost | 86,43% |
| Decision Tree | 82,70% |
| kNN (k=15) | 82,41% |

### 2. Згорткові нейронні мережі (CNN)

Для класифікації зображень використано датасет **Oxford-IIIT Pet Dataset**, який містить зображення котів і собак, розподілені на 37 класів.

Реалізовано два підходи:
- CNN, побудована та навчена з нуля;
- pretrained ResNet18 із заміненим вихідним класифікатором та подальшим донавчанням.

У процесі роботи:
- завантажено та підготовлено датасет;
- візуалізовано приклади зображень різних класів;
- навчено CNN з нуля;
- виконано transfer learning за допомогою ResNet18;
- побудовано learning curves;
- порівняно точність класифікації та час навчання моделей.

**Результати:**

| Модель | Test Accuracy | Час навчання |
|---|---:|---:|
| CNN з нуля | 6,05% | 117,75 с |
| Pretrained ResNet18 | 74,41% | 78,58 с |

### 3. Нейронні мережі для класифікації текстів

Для текстової класифікації використано датасет **SMS Spam Collection**, який містить звичайні SMS-повідомлення та спам.

Побудовано дві моделі на основі GRU:
- GRU з Embedding layer, ініціалізованим випадковими вагами;
- GRU з Embedding layer, ініціалізованим попередньо навченими векторами GloVe.

У процесі роботи:
- виконано токенізацію текстів;
- побудовано словник;
- перетворено токени на числові індекси;
- застосовано padding і truncation для вирівнювання довжини послідовностей;
- навчено обидві GRU-моделі;
- побудовано learning curves;
- порівняно якість класифікації за Accuracy, Precision, Recall та F1-score.

**Результати:**

| Підхід | Accuracy | Precision (spam) | Recall (spam) | F1-score (spam) |
|---|---:|---:|---:|---:|
| GRU + Random Embedding | 95,07% | 87,90% | 73,15% | 79,85% |
| GRU + GloVe | 98,74% | 96,55% | 93,96% | 95,24% |

## Загальні висновки

У ході лабораторної роботи було досліджено застосування нейронних мереж для класифікації табличних даних, зображень і текстів.

Для табличних даних MLP показала результат, практично співставний із класичними алгоритмами машинного навчання. Для класифікації зображень pretrained ResNet18 значно перевершила CNN, навчену з нуля, що продемонструвало ефективність transfer learning. У задачі текстової класифікації використання попередньо навчених GloVe embeddings суттєво покращило результати GRU-моделі.

Також було досліджено learning curves, які дали змогу оцінити збіжність моделей, виявити ознаки перенавчання та недостатнього навчання.

Отримані результати показали, що ефективність нейронних мереж залежить від типу даних, архітектури моделі, обсягу навчальної вибірки та використання попередньо навчених параметрів.

## Запуск роботи

1. Відкрити файл `Lab3_Neural_Networks.ipynb` у Google Colab або Jupyter Notebook.
2. Підключити необхідні бібліотеки та обчислювальне середовище.
3. Для першого завдання завантажити файл `cybersecurity_intrusion_data.csv`.
4. Для третього завдання підключити Google Drive з датасетом `SMSSpamCollection` або налаштувати відповідний шлях до файлу.
5. Запустити комірки notebook послідовно.
6. Для навчання моделей класифікації зображень рекомендується використовувати GPU.

**Примітка:** для другого завдання Oxford-IIIT Pet Dataset завантажується засобами Torchvision. Для третього завдання pretrained embeddings GloVe завантажуються через Gensim.
